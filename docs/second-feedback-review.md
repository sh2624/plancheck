# 팀원 2차 피드백 검증

## 수정 범위

- 단순 수치 비교의 기본 응답은 검토 기록만 저장한다. 기준일·시나리오·확정 여부·항목 확인·연결 승인은 자동으로 생성하지 않는다. 최종 판정에 필요한 기존 상세 입력은 ‘최종 판정 조건 입력’에 유지한다.
- 같은 기준 답변을 저장한 뒤에도 원문 조건이 없으면 ‘수치 차이 확인 · 비교 조건 미확인’, 명시적으로 다르면 ‘기준 불일치’로 표시한다. 원본 지문이 바뀌거나 파일을 교체하면 이전 답변을 무효화한다.
- 예금 배정 질문은 같은 예금의 동시 사용 여부를 명시한다. 답변은 관계 검토이며 날짜를 만들지 않는다. 기존 ALLOC 엔진의 날짜·보유액 기준 등 최종 안전 조건은 유지한다.
- 대표 수치 비교의 표시 단위를 통일한다. 내부 원 단위 값과 차이는 바꾸지 않는다. 작은 차이는 원 단위로 보존하고 금리 차이는 %p로 표시한다.
- ETF의 `중단(~, , 금액)`은 빈 기간·시나리오의 문자열 직렬화였다. 인코딩 문제는 아니다. 표시 계층에서 실제 단계·대상·행동·금액을 문장으로 표시하고 빈 구분자는 생략한다. 원본 텍스트·위치와 엔진 계산 근거 데이터는 유지한다.

## 실제 팀원 파일 확인

비공개 XLSX·DOCX 원본은 수정하거나 커밋하지 않았다. 로컬 Chrome에서 두 파일 등록 → 검사 시작 → 결과 확인 순서로 검사했다. 별도 단위 지정·항목 확인·연결 승인 없이 다음 다섯 검토 대상이 유지된다.

| 대상           | 표시 내용                                                  | 자동 발견과 확정 판정의 구분                |
| -------------- | ---------------------------------------------------------- | ------------------------------------------- |
| 월 잉여금      | Excel 9만 원 / Word 7만 원 / 차이 2만 원                   | 차이 발견, 미확인 조건의 최종 오류는 보류   |
| 총자산         | Excel 3,090만 원 / Word 3,070만 원 / 차이 20만 원          | 표·문단 근거를 대표 발견에 보존             |
| 예금 중복 배정 | 보유 590만 원 / 배정 890만 원 / 동시 사용 시 부족 300만 원 | 실제 사용 시점 등 미확인, 오류 확정 아님    |
| 조건부 금액    | 세액공제 132만 원 / 정부기여금 금액 미확인                 | 미래 예상 자산 반영 문맥이며 확정 오류 아님 |
| ETF 계획       | 4단계 월 15만 원 중단 / 5단계 월 15만 원 자동이체 유지     | 같은 상품·기간 등의 최종 조건 미확인        |

Chrome에서는 잉여금·총자산 각각 ‘이 항목 검토 → 예 → 확인 내용 적용’ 3회로 답변을 저장하고, 입력란이 없으며 다시 열었을 때 응답이 유지되는지 확인한다. 같은 답변 후에도 확인된 오류는 0건이다. Word 교체 후 답변 선택이 해제되는지 확인한다. 복합 세 유형의 예·아니요·모름 각각도 기존 보류 상태와 원본 접근을 검사한다.

## 조작 수 비교와 한계

- 기준 정보가 없는 단순 CROSS 기본 경로는 최소 열기·예·기준일 입력·시나리오 입력·적용 5회에서 열기·예·적용 3회로 줄었다. 날짜·시나리오 입력은 2개에서 0개다. 이는 검토 기록 기준이며 최종 오류 승인 횟수가 아니다. 이전 잉여금 대표 결과의 CALC 구성 편집 경로와 동일한 횟수라고 주장하지 않는다.
- 예금의 기본 관계 답변은 기존과 같은 열기·응답 2회다. 날짜 없는 관계 답변을 최종 ALLOC 오류로 바꿀 수 없으므로 정확한 기간이 필요한 상세 검증은 계속 보류한다.
- 최종 승인 시연은 상세 조건 진입 버튼 1회가 추가된다. 승인 안전 조건을 줄인 것이 아니다.
- 이 검증은 제공된 파일과 회귀 사례의 결과다. 다른 모든 문서에 대한 정확도·오탐률로 일반화하지 않는다. 새로운 규칙, AI 호출, 파서·검증 엔진 변경, 배포는 하지 않았다.

## 검증 결과

- 전체 Vitest: 44개 파일, 347개 테스트 통과. 새 회귀 6개 포함.
- 실제 Chrome: 30개 통과, AI 비활성화에 따른 모의 API 테스트 1개 건너뜀. 팀원 원본 검사, 세 복합 유형의 응답별 상태, 고급 승인, 파일 교체, 1280px·390px 레이아웃을 포함한다.
- 프로덕션 빌드와 포맷 검사 통과.
- 린트 오류 0개, 기존 `ExtractedViews.tsx`의 TanStack Table `react-hooks/incompatible-library` 경고 1개 유지.
- 표시 문구의 마지막 일반 자금 대응 보완 후 관련 회귀 6개, 빌드·린트·포맷을 재확인했다.

로컬 커밋 해시는 작업 완료 보고에 기록한다. 복구 태그 `baseline-before-second-feedback-20261113`은 수정 전 `a7df3a5`를 가리킨다. Production 배포 검증은 이번 로컬 Chrome 검증과 별개이며 수행하지 않았다.
