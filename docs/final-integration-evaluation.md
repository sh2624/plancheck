## 오류 주입·정상 대조 평가

실제 기존 샘플의 읽기 전용 복사본에 평가 부록을 넣는 기존 테스트를 유지했다. CALC·CROSS·ALLOC·조건부 금액·행동 충돌의 독립 오류 5개는 자동 발견과 명시적 확인 후 엔진의 오류 판정을 각각 검사한다. 정상 대조는 통과하고 다른 기준일·시나리오는 보류한다. 이는 실제 팀원 문서에 없는 조건을 그 문서에 있다고 간주한 평가가 아니다.

추가 비식별 ZIP/XML 문서로 임의 상품명·금액, 단계별 문장 분리, 다른 ETF 상품, 두 중단 행동, 다른 기간·대체 시나리오, 부정 표현, 새로 적립한 재원, 배정 관계 없는 목표, 단순 지원 언급, 별도 참고 시나리오, 실제 승인·수령 완료를 검사했다.

- 새 복합 발견 테스트: 21개 사례 중 정상·오탐 방지 대조 13개에서 우선 경고 0개.
- 정해진 오류 주입 5개: 자동 검토 대상 발견 5/5, 원문 조건을 확인한 뒤 기존 엔진의 오류 판정 5/5, 정상 대조 5/5 통과.
- 기준선 실제 팀원 대상의 자동 발견: 2/5 → 5/5. 확정 오류는 0개로 유지.
- 남은 미탐: 일반 자연어 전체를 이해하지 않으며, 다른 표현·대명사·복잡한 표·한 문장에 여러 관계가 섞인 경우 관계를 놓칠 수 있다. 정부기여금 금액처럼 원문에 없는 정보는 추출 실패를 0으로 숨기지 않는다.

## 문맥과 안전 경계

명시된 날짜는 유효성을 확인하고 ISO 표기로 통일하며 선언 위치·범위·명시/상속 근거를 보존한다. 시트 전체·문서 전체 선언만 다른 표·단계로 계속 상속한다. 표 한정 선언은 경계에서 해제한다. 원문에 없는 날짜·기본 시나리오·확정 여부는 생성하지 않는다. 기존 날짜 서식 오인식 방지와 단위 상속을 유지한다.

확보·배정·충당 동사가 있는 관계만 자산·목표에 연결한다. 이름이 같은 보유 자산이 여러 개면 무조건 하나를 고르지 않는다. 유일한 표 근거와 같은 값·조건의 반복 문장이 있는 경우만 대표 보유액에 연결하고 원문 위치를 보존한다. 배정액으로 만든 목표 후보는 목표 전체 예산이 아니라 그 문장의 배정액임을 표시한다.

ALLOC 가정 계산은 기존 ALLOC 함수의 discovery 경로에서만 수행한다. ‘같은 시점에 현재 자산을 사용한다면’이라는 가정을 계산 근거에 명시하며 실제 기간이나 확인 상태를 채우지 않는다. 최종 승인 경로의 확인 게이트는 유지한다.

## 배포 권장과 제외 방법

업로드 즉시 수치 비교는 Production 포함을 권장한다. 복합 관계는 **확인 필요 후보로만** 포함할 수 있으며, 확정 오류 자동 판정 기능으로 소개하면 안 된다. 불확실한 기능을 제외하려면 빌드 환경에 `VITE_ENABLE_COMPOUND_DISCOVERY=false`를 설정한다. 새 복합 관계의 우선 노출과 인라인 질문을 끄고 기본 수치 비교와 기존 고급 엔진을 유지한다. 이 모드에서도 실제 팀원 문서의 두 수치 차이와 원본 근거를 Chrome으로 확인했다.

AI API·모델·서버·활성화 설정은 변경하지 않았다. Production AI 비활성 빌드와 서버 차단은 유지한다. 실제 push·Preview/Production 배포 및 배포 주소 검증은 수행하지 않았다.
