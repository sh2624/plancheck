# Excel 날짜 서식 오인식 수정

## 범위

기본 날짜·시간 서식 ID(14–22, 27–36, 45–47, 50–58)와 사용자 지정 서식의 날짜·시간 토큰을 판별한다. 인용 문자열, 이스케이프, 색상·조건·통화 로캘 코드는 날짜 토큰으로 취급하지 않으며 `[h]`, `[mm]`, `[ss]` 경과 시간은 인식한다.

서식 규칙은 [Microsoft NumberingFormat 문서](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.numberingformat)와 [사용자 지정 서식 안내](https://support.microsoft.com/en-us/excel/review-guidelines-for-customizing-a-number-format)를 참고했다.

날짜·시간 셀은 금액 후보 및 항목명 구성에서 제외한다. 원본 추출의 값·수식·캐시·서식 문자열을 변경하지 않고 서식 ID와 날짜·시간 판별 정보를 추가로 보존한다. 행 문맥에도 원래 값이 남는다. 날짜 일련번호를 달력 날짜로 변환하거나 기준일로 자동 지정하는 기능은 추가하지 않는다.

검증 엔진, 사용자 승인·상태 관리, UI, AI 설정은 변경하지 않는다. 날짜 서식이 없는 일반 숫자를 값의 크기만으로 날짜라고 추측하지 않는다. 원본에서 금액에 날짜 서식을 잘못 지정한 경우에도 서식에 따라 금액 추출에서 제외되므로 원본 수정이 필요하다.

## 회귀 검증

- 기본 날짜·시간 ID, 사용자 지정 날짜·시간, 경과 시간, 금액·백분율·과학 표기·분수·문자 리터럴 테스트 53개.
- 메모리 내 실제 XLSX ZIP/XML을 파서→정규화 경로로 처리하여 날짜 일련번호의 만 원 상속 방지, 실제 금액·금리 유지, 수식 및 원문 문맥 보존을 검사한다.
- 실제 비공개 팀원 파일의 잉여금 2만 원·총자산 20만 원 차이와 원본 근거는 기존 Chrome E2E로 재검증한다. 원본 파일은 변경하거나 커밋하지 않는다.

2026-11-12 검증 결과: 전체 301개 테스트 통과, 로컬 Chrome E2E 18개 통과(AI 비활성으로 Preview 모의 테스트 1개 제외). 팀원 파일의 두 차이는 단위 지정·연결 승인 없이 발견됐고 원본 근거 및 중복 통합도 유지됐다. 프로덕션 빌드·포맷 검사 통과, 린트 오류 0개 및 기존 TanStack Table 경고 1개. 원격 push·배포는 수행하지 않았다.
