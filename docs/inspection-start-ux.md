# 검사 시작 버튼과 준비·실행 상태

파일 등록만으로 검사를 실행하거나 결과 화면을 열지 않는다. Excel·Word 등록 완료 후 ‘두 문서가 준비됐습니다’를 표시하고 사용자가 ‘검사 시작’을 눌러 실행한다. 항목별 단위·기준일·확정 여부·시나리오 확인이나 연결 승인은 검사 시작의 선행 조건이 아니다.

검사 중에는 버튼을 비활성화하고 ‘문서를 비교하고 검토할 항목을 찾고 있습니다…’를 표시한다. 화면이 진행 상태를 그릴 기회를 준 뒤 기존 분석 함수를 실행하고 결과 단계로 이동한다. 퍼센트나 임의 대기 시간을 사용하지 않는다. 기존 분석은 브라우저 메인 스레드의 동기 계산이므로 긴 계산 중 개별 단계 진행률은 제공하지 않는다.

파일 교체·초기화 시 실행 상태와 이전 결과를 무효화한다. 새 파일 등록 완료만으로 재실행하지 않는다. 실행 대기 중 원본이 바뀌거나 컴포넌트가 해제되면 늦은 완료 요청을 무시한다. 기존 사용자 확인·연결·계획 초기화 정책은 유지한다.

실제 팀원 문서에서는 파일 선택 후 **검사 시작 1회, 항목별 사전 확인·연결 승인 0회**로 잉여금 차이 2만 원, 총자산 차이 20만 원, 예금 동시 배정 의심, 세액공제 반영 조건, ETF 중단·유지 관계를 확인한다. 이 다섯 항목은 검토 대상이며 자동 확정 오류가 아니다. 불명확한 조건은 기존 결과의 인라인 확인·상세 검토로 처리한다.

추출·단위 상속·자동 매칭·복합 관계 발견·최종 검증 엔진과 AI 비활성 설정은 변경하지 않는다. 이전 통합 평가의 ‘검사 시작 0회’ 측정은 역사적 기록이며 현재 UX에는 적용하지 않는다.

## 검증

- 단위 테스트에서 렌더링 프레임만 제어해 준비 상태, 진행 문구, 중복 실행 방지, 완료 전환, 파일 초기화에 의한 대기 검사 취소, 재등록 후 명시적 재실행을 검사한다. 이 상태 테스트는 파서를 모의하며 실제 문서 검증과 구분한다.
- Chrome은 실제 비공개 팀원 파일을 사용해 등록만으로 결과가 열리지 않음, 시작 클릭 후 다섯 대상 발견, 원본 위치, 개별 확인 유지, 파일 교체 후 재검사 필요를 확인한다.
- 원본 금융 문서와 테스트 산출물은 커밋하지 않는다. 원격 push·배포는 수행하지 않는다.

2026-11-12 검증 결과: 전체 테스트 329개 통과(기존 327개 유지), 실제 문서 포함 Chrome E2E 19개 통과 및 AI 비활성으로 Preview 모의 테스트 1개 제외. 프로덕션 빌드·포맷 검사 통과, 린트 오류 0개·기존 TanStack Table 경고 1개. 수정 범위는 App 실행 상태, 해당 UI 상태/E2E 테스트와 사용 문서이며 파서·정규화·추천·검증 엔진에는 변경이 없다.
