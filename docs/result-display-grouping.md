# 동일 발견의 결과 표시 정리

검증 엔진이 생성한 결과는 삭제하거나 변경하지 않고, 결과 표시 계층에서 대표 발견과 개별 검사 근거로 나눈다.

- 동일 원본 쌍의 비교는 대표 한 건으로 표시하고 서로 다른 규칙과 판단 근거를 상세에 남긴다.
- 같은 파일·항목명·항목 유형·단위·값·기준일·기간·시나리오·확정 상태이며 공통 원본 위치가 있는 반복 기재도 대표 한 건으로 표시한다. Word 표와 문단의 위치·원문은 각각 보존한다.
- 공통 원본이 없는 별도 쌍, 다른 파일·항목·조건은 합치지 않는다. 연쇄적으로 관련 없는 원본까지 묶지 않도록 그룹 전체에 공통 원본이 있어야 한다.
- CALC는 같은 대상 원본과 조건을 사용하는 CROSS의 비교값이 재계산값과 일치하고 연결 그룹이 하나일 때만 함께 표시한다. 계산 입력과 계산식은 별도 근거로 남긴다.
- 대표 발견은 확인된 오류, 우선 검토 순으로 선택한다. 묶는 과정에서 사용자 확인이나 승인을 생성하지 않는다.
- 개별 근거에서 기존 검토·수정 기능을 사용할 수 있으며, 상세 분석 기록과 유형 필터에서도 근거에 접근할 수 있다.

## 실제 팀원 파일 회귀 확인

비공개 팀원 XLSX·DOCX 원본을 변경하지 않고 로컬 Chrome에서 업로드한다. 연결 승인 없이 잉여금 차이 2만 원과 총자산 차이 20만 원을 발견한다.

- 잉여금: CALC와 CROSS를 대표 한 건으로 표시한다.
- 총자산: 같은 Excel 셀에 대응하는 Word 표·문단 비교를 대표 한 건으로 표시하고 두 위치를 상세에 남긴다.
- 우선 검토와 추가 검토에 같은 발견이 동시에 표시되지 않는지 검사한다.
- 파일 내용이 변경되지 않았고 AI 등 데이터 전송 요청이 발생하지 않았는지 검사한다.

이 변경은 로컬 검증 대상이며 기존 Preview/Production에 배포된 것으로 간주하지 않는다. 파서·정규화·CALC·CROSS·ALLOC·PLAN 엔진과 AI 설정은 변경하지 않는다.

표현이 다른 항목명이나 공통 원본이 없는 관계는 안전을 위해 별도 표시될 수 있다. 대표 표시가 개별 근거의 최종 판정이나 승인을 대신하지 않는다.
